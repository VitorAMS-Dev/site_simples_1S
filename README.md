# Chulamis — Agrotec

Landing page institucional da **Chulamis**, uma empresa fictícia voltada a soluções de tecnologia para o agronegócio. O projeto apresenta serviços com drones, equipamentos, treinamentos, assistência técnica, pesquisa e desenvolvimento.

## Demonstração

Abra o arquivo `index.html` em um navegador ou publique a pasta do projeto em qualquer serviço de hospedagem estática.

## Tecnologias

- HTML5
- CSS3
- Google Fonts
- SVG embutido em CSS

Não há framework, processo de build ou dependências JavaScript.

## Funcionalidades

- Navegação fixa com links para as seções da página
- Banner principal com destaque para tecnologia no campo
- Apresentação da empresa e seus diferenciais
- Cards de serviços
- Indicadores de resultados
- Área de artigos do blog
- Formulário visual de contato
- Rodapé institucional
- Layout responsivo para computadores, tablets e celulares
- Efeitos de hover, gradientes, sombras e animações em CSS

## Como executar

### Abrindo diretamente

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.

### Usando um servidor local

Com Python instalado:

```bash
python -m http.server 8000
```

Acesse `http://localhost:8000` no navegador.

Com a extensão Live Server do VS Code:

1. Abra a pasta do projeto no VS Code.
2. Clique com o botão direito em `index.html`.
3. Selecione **Open with Live Server**.

## Personalização

As principais personalizações podem ser feitas em:

- `index.html`: textos, títulos, links, serviços e informações de contato
- `css/style.css`: cores, tipografia, espaçamento, componentes e responsividade

As fontes são carregadas pelo Google Fonts. A página utiliza Cormorant Garamond nos títulos e Outfit no restante do texto.

## Observações

- O formulário de contato possui apenas a interface visual; ainda não envia dados para um servidor.
- Os links sociais e artigos estão definidos como placeholders.
- As informações de contato e os números apresentados são exemplos e devem ser substituídos antes da publicação.
